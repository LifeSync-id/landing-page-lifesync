Pertanyaan yang Sering Diajukan

Segala hal yang perlu Anda ketahui mengenai LifeSync — fitur, akun, data, dan dukungan.

Umum

Apa itu LifeSync?
LifeSync membantu kamu mengelola keseharian di satu tempat: kebiasaan, keuangan, nutrisi, dan momen harian (Memento). Semua dirancang untuk membuat hidupmu lebih teratur, mindful, dan penuh makna.
Apakah LifeSync bisa digunakan secara gratis?
Ya, tentu saja! Fitur inti seperti Catatan & To-Do List terintegrasi, Habit Tracker mandiri untuk rutinitas harian, Planner & Kalender acara, pencatatan keuangan dasar, serta Notifikasi Standar (pengingat jadwal & task harian) dapat dinikmati gratis selamanya. Anda dapat meningkatkan ke LifeSync Premium kapan saja untuk membuka wawasan finansial berbasis AI, personalisasi notifikasi adaptif, dan sinkronisasi multi-device.

Akun

Apa bedanya mode tamu dan akun?
Mode tamu menyimpan data hanya di perangkat ini, sehingga data bisa hilang jika aplikasi dihapus. Dengan akun, datamu dapat disinkronkan ke cloud dan fitur AI Coach terbuka untuk kamu.
Bagaimana cara mengubah password?
Buka tab Profil, pilih Kelola Profil, lalu isi bagian Ubah Password dengan password saat ini dan password baru. Setelah disimpan, perangkat lain akan otomatis dikeluarkan dari sesi.
Saya lupa password, bagaimana?
Di halaman masuk, ketuk "Lupa Password?", masukkan email akunmu, lalu ikuti kode verifikasi (OTP) untuk membuat password baru.

Fitur

Bagaimana Hari Beruntun dihitung?
Hari Beruntun bertambah setiap hari kamu menyelesaikan minimal satu aktivitas, dan kembali ke 0 jika ada hari yang terlewat. Tetap konsisten untuk menjaga streak-mu!
Apa itu AI Coach?
AI Coach memberi insight dari pola aktivitasmu — misalnya kapan kamu paling konsisten. Fitur ini tersedia untuk pengguna yang sudah masuk dengan akun, dan semakin tajam dengan paket Premium.
Bagaimana cara kerja Notifikasi Terpersonalisasi di LifeSync Premium?
Sistem pengingat cerdas membaca pola waktu aktif dan pencapaian kebiasaan harian Anda. Notifikasi dikirimkan pada momen Anda paling responsif untuk menyelesaikan target, tanpa spam atau pesan yang berulang secara kaku — sehingga konsistensi kebiasaan terbangun secara alami.
Apakah saya bisa mengekspor data saya sewaktu-waktu?
Tentu saja. Kami tidak memberlakukan vendor lock-in. Anda dapat mengekspor seluruh catatan Rich Text ke format Markdown, HTML, dan PDF; rekapitulasi finansial dan habit dalam format CSV/Excel; serta arsip foto memori Memento kapan saja langsung dari menu Pengaturan Profil.

Data & Privasi

Apakah data saya tersinkron ke cloud?
Data pengguna dengan akun disinkronkan ke cloud secara aman. Pengguna tamu hanya menyimpan data secara lokal di perangkat. Sinkronisasi cloud tingkat lanjut (multi-device) tersedia eksklusif untuk pengguna Premium.
Bagaimana keamanan data profil, catatan, dan keuangan saya?
Privasi dan integritas data adalah prioritas tertinggi kami. Seluruh dokumen Rich Text, histori habit, dan pencatatan kas tersimpan di perangkat lokal dengan standar enkripsi end-to-end. Kami menganut prinsip zero ad tracking — data pribadi Anda tidak pernah dijual ke pihak ketiga maupun pengiklan.
Bagaimana arsitektur Offline-First memastikan aplikasi tetap lancar tanpa internet?
LifeSync dibangun di atas arsitektur Local-First. Seluruh operasi baca dan tulis langsung dieksekusi pada database lokal perangkat dengan latensi 0 ms. Saat berada di pesawat atau tanpa sinyal, Anda tetap dapat mencatat jadwal dan to-do list. Begitu koneksi internet pulih, engine sinkronisasi otomatis menyelaraskan data ke cloud secara aman.

Bantuan

Bagaimana cara menghubungi dukungan?
Buka tab Profil, lalu pilih Hubungi Kami untuk mengirim email ke tim kami. Atau kamu bisa langsung menjangkau kami melalui partnership@lifesync.id.
